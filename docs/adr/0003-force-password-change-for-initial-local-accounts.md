# 0003. 本地账号首次登录必须修改初始密码

日期：2026-08-03

## 决策

管理员创建本地账号时，系统固定设置初始密码 `123456`，并为该本地身份设置“必须修改密码”状态。使用初始密码成功认证后，用户只能查看会话、退出或修改密码；完成改密前不能调用任何业务接口。

管理员重置密码时恢复该初始密码、撤销已有会话，并再次要求用户改密。已登录用户仍可随时主动修改密码。

## 背景与取舍

统一初始密码降低管理员建号成本，但若只依赖前端提示会留下可绕过的弱密码窗口。将状态存放在本地身份并由服务端路由组强制检查，可以兼容未来 OA 身份，同时保证首次改密是实际访问边界而非界面约定。
