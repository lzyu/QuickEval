# 0004. 分离超级管理员与运营管理员

日期：2026-08-03

## 决策

QuickEval 固定使用三个角色：`super_admin`、`operator` 与 `member`。

- 超级管理员拥有全部菜单与能力，并独占用户管理。
- 运营管理员保留原管理员的全部业务运营能力，但不能查看或管理用户。
- 成员保留现有的评测、Badcase 与内容归属权限。

既有 `admin` 账号迁移为 `operator`；初始化管理员创建为 `super_admin`，确保系统始终有一个可管理用户的最高权限账号。

## 背景与取舍

用户账号管理涉及角色授予、启停和密码重置，应仅交由极少数责任人。评测配置、评测集和 Badcase 运营则需要更广泛的日常管理权限。用固定角色而非可配置权限矩阵，能以较小的实现与审计成本满足职责分离，同时避免运营管理员自行提升权限。
